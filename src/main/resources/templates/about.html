About CampusGuard

CampusGuard is a smart, enterprise-grade college lost and found management platform built using Spring Boot, Java 21, and PostgreSQL.

Key Architectural Highlights
  • Smart Matching Engine: Java composite score matching (Text 40%, Location 20%, Date 15%, Category 10%, Brand 10%, Color 5%).
  • Ownership Secret Verification: Confidential private mark verification algorithm with confidence scoring.
  • Anti-Fraud & Trust System: Internal trust score calculation and suspicious flag detection.
  • Security Officer Handover Desk: Unique reference generator (CG-HO-2026-XXXXXX) with official student ID validation.
